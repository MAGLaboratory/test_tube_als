# Test Tube ALS

This repository contains the software for making an ambient light sensor which
is contained in a 10mm test tube.

Most of the internal components are made from printed circuit boards.
The ambient light sensor itself is a TSL2561 which is still attached to its
breakout board.

The circuit boards inside the HMI are purchased from your typical boardhouse.

The circuit board itself can be located at [this link](https://github.com/blu006/blu_BOB_and_MISC/tree/main/2026/als_board).

## Motivation

We need an ambient light sensor for the outside.
